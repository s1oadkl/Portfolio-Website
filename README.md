# Portfolio Website

A simple portfolio website template built with HTML, CSS, and JavaScript.

## Files

- `index.html` — homepage structure and content.
- `styles.css` — responsive styling and theme.
- `script.js` — smooth scrolling and simple reveal animations.

## Open locally

1. Open the `portfolio-website` folder in VS Code.
2. Open `index.html` and use Live Server or a browser to preview the page.
3. Update the text and links with your personal details.
