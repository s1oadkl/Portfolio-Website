## How to Run the Website

1. Download or clone this repository.

```bash
git clone https://github.com/s1oadkl/Portfolio-Website.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional installation is required.

## Updating the Website

After making changes to the website, use the following commands:

```bash
git add .
git commit -m "Update portfolio website"
git push
```

GitHub Pages will automatically update the live website after the changes are pushed.
